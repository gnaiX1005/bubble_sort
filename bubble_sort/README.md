# Bubble Sort

一個Python實現的氣泡排序演算法。

## 功能

- 氣泡排序法 (Bubble Sort) 的基本實現

## 使用方法

```python
from bubble_sort import bubble_sort

arr = [64, 34, 25, 12, 22, 11, 90]
sorted_arr = bubble_sort(arr)
print(sorted_arr)  # [11, 12, 22, 25, 34, 64, 90]
```

## 複雜度

- 時間複雜度: O(n²)
- 空間複雜度: O(1)
- 穩定性: 穩定

## 執行

```bash
python3 bubble_sort.py
```
